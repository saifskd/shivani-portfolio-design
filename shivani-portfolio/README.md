# Shivani Jain — Graphic Designer & Visual Storyteller Portfolio

An interactive, comic-book styled graphic design portfolio website built with HTML5, CSS3, and vanilla JavaScript. The site presents Shivani Jain's visual identity, creative toolkit, featured design projects, career journey, resume, and direct contact details across six comic-styled chapters.

## About This Portfolio

Built with a comic book aesthetic, every section acts as a "chapter," each design project is presented as an "issue," and the website features rich panels, thick borders, halftone textures, speech bubbles, and an accessible fullscreen lightbox.

The design utilizes a cohesive color palette of deep burgundy (`#4A0E1C`), soft blush pink (`#F2CDD3`), and warm beige (`#EEE3D2`).

## Chapters

1. **Chapter 01 — About Me**: Comic panel introduction to Shivani's design philosophy, creative approach, and background.
2. **Chapter 02 — My Creative Toolkit**: Filterable software toolkit (Adobe Illustrator, Photoshop, InDesign, CorelDRAW, Canva, Premiere Pro, CapCut) and core design capabilities.
3. **Chapter 03 — Selected Work**: Nine image-led design entries across Product Advertising, Social Media, and Editorial & Covers, complete with an accessible interactive lightbox and multi-page magazine viewer.
4. **Chapter 04 — My Journey**: Connected timeline detailing experience at Beta Soft Technology, self-initiated projects, freelance video editing, education (MBA & B.Com Hons), and certification.
5. **Chapter 05 — Resume**: A compact summary card with a direct download for the DOCX resume.
6. **Chapter 06 — Let's Create Something**: Direct contact cards with one-click email and phone connectivity.

## Tech Stack

- HTML5 (semantic structure and accessibility)
- Vanilla CSS3 (custom design system, grid, flexbox, keyframe animations, responsive breakpoints)
- Vanilla JavaScript (ES6+, progress tracking, category filtering, accessible keyboard-navigated lightbox)
- Google Fonts: Anton, Permanent Marker, Work Sans

## Running Locally

Open `index.html` directly in any modern browser, or run a local static server:

```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
